Prueba RTS

La mano izquierda mueve el cursor. Da dos toques rápidos en la zona «2 toques» para seleccionar lo que señala. «Añadir» permite seleccionar varias unidades. «Grupo» selecciona todas.

Con el botón derecho Ordenar: terreno → mover; bosque → recolectar (trabajadores); enemigo → atacar. Para construir: selecciona un trabajador, pulsa Cuartel, mueve el cursor y da dos toques. Selecciona un cuartel terminado para reclutar.
