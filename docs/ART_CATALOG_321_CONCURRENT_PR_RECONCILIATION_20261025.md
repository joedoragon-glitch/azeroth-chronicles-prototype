## 3. What the compatibility verdict means — and does NOT mean

A CLEAN three-way Git result means changes can be textually combined on the pinned sources. A successful **small combined native test** means the named functions and source contracts executed together without breaking those checks. **Neither is a full simultaneous eight-PR integration test, nor a rendered multi-mode screenshot across every stage.** The checked PRs can advance independently; therefore **any head change requires rechecking the exact merge tree and the impacted focused tests** before accepting it.

The two inherited conflicts (#445 and #447) are not "fixed" or compatible by simply making #469 green. They must remain explicit upstream integration gates; do not resolve them here through guessed changes to unrelated pipelines or browser tests. This PR should not be used as a shortcut to shipping those drafts.

The original assessment files in this PR are **timestamped earlier checkpoints**. Claims within them that no live screenshots or no source fixes had yet been performed describe the historical audit stage **only**. The latest evidence above supersedes those stage-local progress claims. The complete 513-row catalog remains art-authority; the newer verified `shared:loot` paired capture records **one candidate repair** and does not change the original historical creative acceptance. All other current-Pixi per-asset review verdicts remain unaccepted.
