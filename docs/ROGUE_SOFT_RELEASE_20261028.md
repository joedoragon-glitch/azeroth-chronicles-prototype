# Rogue quiet-release checkpoint — 28 October 2026

- Keep the existing female bell-staff Rogue and crowned procedural appearance unchanged. Owner accepts these designs for initial playtesting, with possible aesthetic refinements later.
- Register existing fourth-class stats, talents, moving basic attacks, lawful Charm and all 16 paired musical actions before loading saves, New Game and Succession. Remove the URL preview gate. Preserve the existing class-independent native fixture opt-in for historical three-class regression baselines.

Preserve the owner-approved Skill 5 **placed magical music stations**, current Endure, separate critical intensity authoring (default Level 2, developer-only) and existing combat/worker mechanics.

**No marketing:** no launch banner, community announcement, promotional release copy or new promised timeline. Existing players may discover Rogue organically.
