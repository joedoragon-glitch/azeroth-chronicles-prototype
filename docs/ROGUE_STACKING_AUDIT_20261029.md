# Rogue rotation stacking audit — 29 October 2026

**Scope:** Source-grounded review of Rogue Normal/Charged skills, enemy debuffs and music stations. The only **implemented gameplay change in this PR** is independent stacking of the two Skill 1 basic-attack boons. Every other row is an **assessment/proposed follow-up**, not a claim that code now stacks that way. Current source owners are `src/prototype/hero-combat.js`, `party.js`, `combat.js`, `progression.js` and `rules.js`.

## Player-authorized design intent

Reward well-timed rotations. Effects from **different legal performances** may remain active together while their individually earned durations remain; Normal and Charged forms may contribute separately when the bonuses represent independently earned, useful effects. A same-form recast refreshes its own effect, never multiplies it without bounds. No effect may bypass legal combat targeting, LOS, control immunity, resource/cooldown rules, death or area geometry. Ally bonuses include the Rogue when applicable.

**Implemented here — Skill 1:** Normal grants +5% basic damage for 4s, Charged +7% for 5s. Each has a separate unsaved per-recipient timer. Both yield **+12% additive basic damage** during overlap, independently on the Rogue and in-range active living companions. Expiring either leaves the other; repeating a form refreshes only that form. This affects ordinary/automatic basics, not special attacks, hit counts, Charm probability or manual critical levers. The normal/charged casts themselves do damage, without a new enemy status. Automatic basics do damage and retain primary-only Charm, with no new ally boon.

## Key existing interaction and hazard

- **Different boon families already coexist.** Skill 2's ordinary recovery and Skill 6's special recovery combine in `combat.js::cooldownRecoveryElapsed` under an aggregate **+25%** limit.
- **Enemy Slow currently has unbounded stack count.** `combat.js::applySlow` uses `Infinity` for hostile `maxStacks`, though the party side is capped at four. Frequent Skill 5 station pulses and Skill 2 casts can therefore continue suppressing enemy cooldown recovery with diminishing returns but without a ceiling. This deserves a separate test-driven upper bound that still rewards repeated lawful Slow hits; it is **not** changed implicitly by this PR.
- **Status layering is not the same as adding identical percentages.** Slow, Weaken, Silence, Wither and actual cooldown debt can coexist where each is legally applicable. Same-kind magnitude rules, independent expiries, boss immunities and timed healing-pool accounting need explicit tests before other additive changes are merged.
- **The render/UI should expose each independent live source clearly**, e.g. +5% Normal and +7% Charged rather than a single misleading +7%, without costly per-frame status scans. The Skill 1 journal explanation is updated in this PR.
- **Critical semantics stay unchanged:** one frozen legitimate critical release per skill cast; no rolls per allied recipient, per DoT/HoT tick, or per station pulse.
- **Transient state stays transient:** do not serialize boons into campaign saves, allow them to persist across zone/rest/reload, or mutate a companion's permanent `damage` field.
- **Performance:** keep per-recipient constant-time lookups, capped number of families, and no new per-frame iteration over all enemies/companions. Any later per-form HoT/DoT work should use finite bounded records and existing tick owners.
