**Purpose and owner mandate:** This is the durable, **remaining-work** assessment after the straightforward Greenwood name/lore/slot mapping was already prepared in PR #289. Refer to each latest branch and issue again before implementation; some old check-status remarks in these PR bodies refer to superseded commits. **Nothing described as "implemented on branch" is automatically integrated into main.** All ratings below are **comparative engineering estimates, not measured durations, CI verdicts or promises**.

### Relative-effort scale
- **Moderate:** a localized extension to an existing attack/status/UI primitive, with proper tests.
- **Substantial:** multiple coordinated mechanics, animation/sound, encounter balance or migrations across several files.
- **High:** movement/combat/save integration, progression changes, significant cross-branch conflicts or complex state/softlock risks.
- **Feasibility:** all reviewed *approved* targets currently look achievable through the existing **multi-file GitHub Pages/PWA** game's extensible architecture. No complete engine rewrite has been demonstrated necessary. This is **not a proof** that each combination is balanced without real testing.

### Ranked engineering bottlenecks

1. **Cindermaw's patrol + Vera escort + wide-area Broodscreen/warband + seven-move system**: many cross-system rules in one fight. Implement/test escort, native reinforcement, owned summons, and actual regular techniques independently **after** explicit authorization.
2. **Finale/coronation state machine**: multiple entry/reload paths and pre-earned TRUE flags; an off-by-one progression transition could lock players out of credits. Preserve #266 over conflicting old #256 text.
3. **Multi-branch combination**: the largest overall risk. Parent/dependent VFX branches and #230/#258 conflicting Lifebinder code require a deliberate integration ledger, not a blind merge.
4. **Thornfang's long boss patrol**: already-supported pathfinding does not guarantee legal boss damage/leash, saved home/respawn or findability. Guard the entire two-defeat TRUE flow.
5. **High-attack-count beginner/captain fights**: Lifebinder, Dreadmaw and other revamped bosses need fair scheduling, sensible overlapping control, and no damage-immune softlock. Check actual fights rather than asserting conceptual feasibility.
