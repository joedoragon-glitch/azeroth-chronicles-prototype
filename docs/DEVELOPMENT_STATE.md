# Current development state

**Thorn introductory-retreat routing — dev.230 candidate (29 October 2026):** The previously 20,501-probe Thorn encounter contained two expensive operations: deciding if the chosen patrol destination was reachable and then synchronously computing the full movement route. The proposed change uses the same collision-validated 50-unit grid and destination priority, an existence-only search for the decision, and a separate bounded incremental planner for the *passive* withdrawal (768 terrain probes / 240 nodes per update, not shared with ordinary enemies or companions). It retains validated waypoints through temporary direct-line visibility changes, refreshes paths when obstructed and discards pending planning on hero-first interruption. Tests must cover native path/goal parity, 24-tick peak probes, completion, repeated-replan prevention and interruption. This is **not** a general fix for boss/captain navigation [#615](https://github.com/joedoragon-glitch/azeroth-chronicles-prototype/issues/615). **Draft/unmerged, unpublished, device-unverified.**

**Dev.229 hostile-projectile target-roster reuse — merged and published 29 October 2026:** [PR #628](https://github.com/joedoragon-glitch/azeroth-chronicles-prototype/pull/628) reuses live ordered party references across consecutive hostile misses, invalidating after native hits, terrain/arc-impact callbacks or an interleaved friendly projectile. ## Current player entrypoints and bilingual navigation

- **Browser/Chromebook:** [normal game entry](https://joedoragon-glitch.github.io/azeroth-chronicles-prototype/). **Phone/PWA:** [phone.html](https://joedoragon-glitch.github.io/azeroth-chronicles-prototype/phone.html). Both use the same campaign engine, device-local save namespace, and multi-file offline-ready web application; desktop and phone controls differ.
- **Cold launch:** current code shows the **main title menu** rather than immediately simulating a loaded campaign. English title actions: **Continue Adventure**, **New Game**, **Saved Games & Backups**, **Settings**, **Help & Credits**. Spanish: **Continuar aventura**, **Nueva partida**, **Partidas y copias de seguridad**, **Ajustes**, **Ayuda y créditos**. Continue is enabled only when a valid saved adventure can safely resume; incomplete/failed saves retain backup/recovery routes. Returning from an *active* session via **Return to Main Menu** saves with existing safeguards. Minimizing and restoring an already running app is not a cold launch.
- **Settings and save controls (English):** **Game and settings → Screen and performance → Export playtest report** for the JSON diagnostic/version report; **Game and settings → Save and game management → Save backups → Export save / Import save** for campaign backups. **Game and settings → Screen and performance → Graphics renderer** offers **Canvas 2D · Default** and **PixiJS WebGL2 · Experimental**, with an independent 15-second Keep/Revert trial when WebGL2 is selected.
- **Spanish in-game labels:** **Juego y ajustes → Pantalla y rendimiento → Exportar informe de prueba**; **Juego y ajustes → Partidas guardadas → Copias de seguridad → Exportar partida / Importar partida**. Graphics renderer is the same experimental choice, localized by the game where available. English/Spanish support is **partial**, not a claim that all world text is translated.
- **Update and version check:** **Game and settings → Check for game update** / **Install available game update** (Spanish **Juego y ajustes → Buscar actualización / Instalar actualización** when offered), then **Export playtest report** to inspect `version` *on that device*. Save-export is a different file and is not a diagnostic report; the game does not send telemetry automatically.

**Current class selection:** Normal New Game now offers four classes: Paladin, Mage, Ranger and Rogue (Pícara). Earlier Rogue preview-query instructions and draft-only release gates are dated history, not the current player entrypoint. The live release is a functional soft launch with further owner phone/boss/performance acceptance pending.

Player guides: [English README](../README.md) and [Guía en español](../GUIA_EN_ESPANOL.md). The labels above were inspected in `src/prototype/app.js` on the pinned commit; they describe the source implementation, not a completed phone/browser acceptance test.
