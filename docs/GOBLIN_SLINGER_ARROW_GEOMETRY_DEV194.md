# Goblin Slinger equipment and straight arrow presentation — dev.194

**Owner decision, 26 October 2026.** During Greenwood field play the owner noticed Goblin Slingers/Ringleaders were armed with a bow and arrow quiver while firing **real stones**. The owner explicitly selected a readable leather sling and satchel of stones rather than renaming them as archers. The friendly companion Goblin Archer must retain its approved bow/quiver. The owner also observed awkwardly bent arrow trails in Ranger/Archer ordinary fire and normal Ranger Skill 1. Autonomous implementation, focused aesthetics/technical audit and merge were authorized.

## Source-rooted fixes
1. `src/prototype/visuals.js::goblinBody(crown,ranged,friendly)` previously placed `backQuiver` and `bow` on every ranged Goblin, including hostile Slingers. The branch now reserves that loadout for `friendly && ranged`. Hostile ranged variants instead draw a two-cord hand sling with a loaded stone cup, loose release cord, and waist-side stone satchel visibly containing spare stones. Keep the approved sly expression, shared Goblin anatomy, Crown/Ringleader clothing and melee sword. No new sprite, atlas, image generation, registration, hitbox, AI, stone projectile, damage or save change.
2. `src/prototype/renderer.js::drawProjectileBody` was explicitly using `quadraticCurveTo` in the normal-arrow combo-2 flourish, creating a visibly bent ribbon behind an otherwise straight physical arrow. The flourish is replaced by a short low-alpha straight accent parallel to the projectile's actual `dx/dy`. The shaft and feathers remain. `hero-presentation.js::projectile` already draws Ranger Skill 1 from the launched independent collider vector; `combat.js` correctly re-aims *pending* Ranger/Archer shots at their moving caster's location only when released. No caster-tether is added to arrows and no gameplay timing/targeting/collision changes.

**Shared rendering:** Canvas 2D and PixiJS procedural actors use the same `PrototypeVisuals.draw` art; in Pixi, arrows use the existing overlay. Both receive the fix without duplicating drawing logic.

## Verification and aesthetic acceptance
Focused tests invoke actual procedural drawing for regular/leader/Crown Slingers, melee Goblins and friendly Archers, checking that slings, carried stones and the loaded pouch appear only for appropriate hostile variants while the friendly Archer retains a bow. They verify Ranger normal Skill 1's drawn shaft remains world-locked when the hero moves and no arrow branch contains curved-trail commands. Visual composition uses broad contrasting cords, open stone pouch mouth and a single prominent stone silhouette for readability at phone zoom; no tiny duplicate arrow ornaments or rigid bow contours. This engineering evaluation is not a claim of owner-reviewed screenshot approval. Only the owner's morning playtest supplies final personal aesthetic feedback. Focused CI + reproducible PWA build gate the release; no comprehensive browser matrix was requested.
