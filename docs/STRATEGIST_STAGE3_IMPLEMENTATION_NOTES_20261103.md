- [Material PR #770](https://github.com/joedoragon-glitch/azeroth-chronicles-prototype/pull/770) owns genuine environmental Water, Mineral (never dirt), Wood and active Fire selection, including the forGather(game,material,options) API with worker authorization, real route and passability. That source is unmerged and has not been copied into the Stage 3 branch.
- Current navigation.js route() uses the active Campaign zone. It does not directly solve paths for an inactive reserve in another zone. A **native zone-aware** movement adapter and an authenticated reserve home/position are required; neither can be faked by changing the active zone. The new domain refuses to gather without source, navigation, danger, origin and source-verification adapters.

## L1–L3: Implemented as a dormant Campaign domain

The isolated src/prototype/strategist-field-labs.js module has an install(Campaign, adapters) API compatible with other Campaign domain modules, but is **not in the browser script graph** and has **no live tick call**. The tests inject deterministic, explicitly limited substitutes for future actual adapters.

1. **Real building lifecycle:** Paid Strategist-only placement creates a distinct, one-per-outdoor-region Field Lab in zone.buildings. A previously placed unfinished native player-built Barracks (with the native barracks- ID family) qualifies; similarly named settlement scenery does not. A known reachable clear site is required, plus native crown spend, and duplication/payment errors fail without a partially created Lab. Locally simulated construction progresses on authorized active tick calls only.
2. **Central management and training:** One locally established Lab can manage the existing network. Only the Strategist may create, assign, unassign, upgrade the windmill or pay for separate Neri Advanced Alchemy capacity training. A trained owned inactive reserve may be used after an affordable one-time paid qualification. The actual roster, live health, order/expedition exclusivity, genuine Charm receipt and recognized pet provenance are mandatory. An eligible active idle companion can be **explicitly** assigned and is then removed from the active combat party while laboring; starting Soldier/Archer are never automatically reassigned. An inactive reserve is also eligible. Every selected worker's region and position must be externally authenticated before assignment.
3. **Genuine routed trip contract:** A qualified worker receives a selected Water/Wood/Mineral/Fire job. The material provider must return a real authored source after checking an actual valid route. The worker position traverses finite outbound waypoints, samples only after current source revalidation, traverses a return route and deposits finite goods. Blocked travel or danger does not produce samples. No invisible instant delivery. Only one worker may request source selection per simulation tick, with scheduled retries, and blocked outbound/return routes are retried at most once per cooldown, and accepted outbound paths are reused rather than recalculated. **Live enemy fights, actual damage and remote reservation travel are HOLD until native companion/navigation adapters are implemented.** The synchronous #770 selector can still test up to 24 candidate routes per single call; budgeted search and actual CPU profiling remain required.
4. **Finite shared processing:** Stored authentic samples convert one-for-one into Water Reagent, Wood Essence, Mineral Catalyst and Fire Elixir. A paid windmill, available without Neri, defaults to Acid production priority, preserving incoming samples until two different surplus types can be converted into **one** Bottle. A Strategist may explicitly select reagent or balanced processing instead in the same s.strategistAcidBottles stock used by E0 and future learned Acid. A legitimate trained idle worker must operate the machine. The recipe leaves one sample of each type as reserve, and no input can produce free stock. Samples, products and bottles observe a provisional shared storage cap.
5. **Time and class boundaries:** No Date.now, background timers or offline catch-up. Explicit game-clock delta is limited to 0.1 second per call. Active remote Labs continue at positive, reduced gathering/processing efficiency. A non-Strategist lawful successor can retain staffed passive production but cannot build, staff, train or upgrade Labs. Merely installing the module never writes Lab fields onto any of the original four classes.

**Provisional numbers are NOT approved balance:** Lab 50 crowns, training 20, windmill 75, three Neri ranks 65/95/130, one starting worker slot, storage 36, construction 20 simulated seconds, 90 world units/second trip movement, six-second processing and 55% remote efficiency.

## Focused validation and limits

The source includes tests/strategist-field-labs.test.cjs to exercise old-class isolation, unfinished Barracks, duplicate and cost failures, one-time qualification, reserve-location refusals, forged Charm/pet rejection, route blockage, physical waypoint progression, vanished sources, finite products and Acid, remote slowdown, no offline accrual, successor management denial, event-gated searches, danger hold and independent Neri purchasing. They use a **controlled test adapter**, not actual PR #770 or remote native route and enemy AI; passing them can support only an isolated-domain test claim. Full browser, save import/export, real hardware and long-run CPU have not been executed for this work.

## L4/L5 integration handoff — genuinely blocked dependencies

- **Class/save:** Exact-head reconcile with E0 #780; preserve its shared Acid field and v4 validation; explicitly validate/restore Lab buildings, provenance, jobs, stock and worker coordinates. Four-class saves must never receive new default Lab fields. Succession must preserve lawful qualifications and assignments without duplication.
- **Source and navigation:** Use #770 as the single truth for materials, and establish genuine budgeted navigation across active and inactive regions. Do not abuse an active-zone route for remote Labs. Prove reserve zone from source ownership, not guessed x/y.
- **Threats/performance:** Integrate actual ordinary enemy encounter/damage/withdrawal/recovery behavior and bounded route work; measure cold and crowded CPU p95/p99 before live acceptance. A conservative test danger-stall guard is not a fully implemented enemy fight.
- **UI/art:** Bilingual Barracks/Lab controls, centralized five-zone management, real plot interactions, five region-appropriate Lab drawings and visibly turning small windmills remain unimplemented.
- **Neri/combat:** Advanced Alchemy capacity and reagent education are distinct from Neri's five separately bought combat lessons. Source-substitution spends on actual skill success belong to Stage 2. Stage 1 third landed dagger consumes the same Acid field; Stage 4 inherited chance-based Acid is not implemented.
