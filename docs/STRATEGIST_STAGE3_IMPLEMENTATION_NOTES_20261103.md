## L1–L3: Implemented as a dormant Campaign domain

The isolated src/prototype/strategist-field-labs.js module has an install(Campaign, adapters) API compatible with other Campaign domain modules, but is **not in the browser script graph** and has **no live tick call**. The tests inject deterministic, explicitly limited substitutes for future actual adapters.

1. **Real building lifecycle:** Paid Strategist-only placement creates a distinct, one-per-outdoor-region Field Lab in zone.buildings. A previously placed unfinished native player-built Barracks (with the native barracks- ID family) qualifies; similarly named settlement scenery does not. A known reachable clear site is required, plus native crown spend, and duplication/payment errors fail without a partially created Lab. Locally simulated construction progresses on authorized active tick calls only.
2. **Central management and training:** One locally established Lab can manage the existing network. Only the Strategist may create, assign, unassign, upgrade the windmill or pay for separate Neri Advanced Alchemy capacity training. A trained owned inactive reserve may be used after an affordable one-time paid qualification. The actual roster, live health, order/expedition exclusivity, genuine Charm receipt and recognized pet provenance are mandatory. An eligible active idle companion can be **explicitly** assigned and is then removed from the active combat party while laboring; starting Soldier/Archer are never automatically reassigned. An inactive reserve is also eligible. Every selected worker's region and position must be externally authenticated before assignment.
3. **Genuine routed trip contract:** A qualified worker receives a selected Water/Wood/Mineral/Fire job. The material provider must return a real authored source after checking an actual valid route. The worker position traverses finite outbound waypoints, samples only after current source revalidation, traverses a return route and deposits finite goods. Blocked travel or danger does not produce samples. No invisible instant delivery. Only one worker may request source selection per simulation tick, with scheduled retries, and blocked outbound/return routes are retried at most once per cooldown, and accepted outbound paths are reused rather than recalculated. **Live enemy fights, actual damage and authenticated reserve location are HOLD until native companion/worker owners are integrated.** A new zone-explicit adapter shares a finite route decision budget across all up-to-24 candidates in #770, and individual movement steps use short-segment collision checks. This avoids an unbounded number of full-path solves in one decision; real crowded-frame profiling and source-native integration remain necessary.
4. **Finite shared processing:** Stored authentic samples convert one-for-one into Water Reagent, Wood Essence, Mineral Catalyst and Fire Elixir. A paid windmill, available without Neri, defaults to Acid production priority, preserving incoming samples until two different surplus types can be converted into **one** Bottle. A Strategist may explicitly select reagent or balanced processing instead in the same s.strategistAcidBottles stock used by E0 and future learned Acid. A legitimate trained idle worker must operate the machine. The recipe leaves one sample of each type as reserve, and no input can produce free stock. Samples and processed reagents share the bounded **Lab warehouse**. Carried Acid Bottles are stored only in E0's canonical `s.strategistAcidBottles` inventory, under E0's independent 1,000-bottle provisional cap. A legitimately carried bottle never consumes a Lab warehouse slot.
5. **Time and class boundaries:** No Date.now, background timers or offline catch-up. Explicit game-clock delta is limited to 0.1 second per call. Active remote Labs continue at positive, reduced gathering/processing efficiency. A non-Strategist lawful successor can retain staffed passive production but cannot build, staff, train or upgrade Labs. Merely installing the module never writes Lab fields onto any of the original four classes.

**Provisional numbers are NOT approved balance:** Lab 50 crowns, training 20, windmill 75, three Neri ranks 65/95/130, one starting worker slot, storage 36, construction 20 simulated seconds, 90 world units/second trip movement, six-second processing and 55% remote efficiency.

## L4: Source-coded adapters and controlled integration boundaries

**Remote pathfinding — implemented in isolation:** strategist-lab-navigation.js uses the native Campaign.blocked(x,y,zoneId,15) geometry for both direct segment validation and bounded graph search. It does not temporarily change s.zone, enemy simulation or hero position. Shared node/probe budgets refuse over-budget routes instead of making source access magically true. A new native Marches test builds the actual region and verifies a remote segment while the hero remains in the Vale. This is route feasibility, **not** verified worker gathering on a live fifth-class save.

**Worker danger — observation implemented, live combat HOLD:** strategist-lab-threats.js reads real zone.enemies, native acquisition ranges, injected authentic sight and a 0.4s per-worker cache. Ordinary enemies and hostile summons can suspend gathering with a threat identifier; neutral, dead or returning enemies are not invented threats. The domain stops source sampling and processing while unsafe. Actual remote combat AI, HP damage, pursuit, retreat and recovery do not run in dormant code. Claiming that a remote worker fought an enemy would be false; integration with the single active-zone combat owner is still required.

**v4 save — source changes isolated from live release:** strategist-lab-save.js validates one founder-certified Lab bank, exact five-region placed buildings, bounded finite ingredients/products, the canonical Acid stock and per-worker real-position/order receipts. The draft save.js integration preserves authenticated Lab work orders and avoids incorrectly snapping off-zone workers onto the hero's collision map; four-class snapshots stay on their original normalization path. The fifth hero is not registered, and there is no live browser script registration. This does **not** constitute a successfully restored fifth-class live campaign; compare and resolve conflicts with E0 #780 before any merge.

**Bilingual menu catalog — implemented but not activated:** strategist-lab-menus.js provides direct English/Spanish copies for network listing, worker training/assignment/release, stock, windmill, processing priorities and Neri capacity. Every action rechecks the current local Lab and Strategist owner guard. The live app and menus.js do not yet show these controls; they must only be wired when class admission, save and source/route integration are real.

**Five Lab visual variants — procedural routines, not displayed live:** strategist-field-lab-visuals.js contains five region-appropriate palettes and outlines for separate player-built Labs, with a compact eight-frame rotor driven by the simulation clock. The renderer does not mutate stock. These routines are not yet connected to Canvas/Pixi scene composition. Because active Dark Crown draft #769 touches renderer.js, visuals.js and pixi-experimental.js, renderer hook-up must reconcile that branch to avoid losing unrelated work; the rotor belongs in a time-varying overlay on Pixi rather than baking animation into static GPU textures. No device or perceptual acceptance has occurred.
