## L1–L3: Implemented as a dormant Campaign domain

The isolated src/prototype/strategist-field-labs.js module has an install(Campaign, adapters) API compatible with other Campaign domain modules, but is **not in the browser script graph** and has **no live tick call**. The tests inject deterministic, explicitly limited substitutes for future actual adapters.

1. **Real building lifecycle:** Paid Strategist-only placement creates a distinct, one-per-outdoor-region Field Lab in zone.buildings. A previously placed unfinished native player-built Barracks (with the native barracks- ID family) qualifies; similarly named settlement scenery does not. A known reachable clear site is required, plus native crown spend, and duplication/payment errors fail without a partially created Lab. Locally simulated construction progresses on authorized active tick calls only.
2. **Central management and training:** One locally established Lab can manage the existing network. 3. **Genuine routed trip contract:** A qualified worker receives a selected Water/Wood/Mineral/Fire job. The material provider must return a real authored source after checking an actual valid route.
