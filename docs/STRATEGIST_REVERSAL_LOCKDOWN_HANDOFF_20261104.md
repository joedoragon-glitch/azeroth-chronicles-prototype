It binds manual input to one live, spatially readable native warning through an **unsaved WeakMap receipt** keyed by the actual warning object and checked against campaign, hero, zone, source, attack instance and current telegraph at release. Each native release can be countered only once. Separate sequential/overlapping warnings stay independent; no encounter quota, permanent party immunity or invented Reversal cooldown was added. Invalid, late, obstructed, outside or duplicate input does not spend any Reversal cooldown. A countered damaging attack reflects source-native force at its actual caster; status-only releases cancel their own effect without synthetic damage.

**Release owners audited/modified:** `boss-combat.js::resolveAttack` for ordinary boss, captain, night and ordinary Rogue warns, `cindermaw-combat.js::resolveAttack` for Cindermaw Distraint, delegation member and finishing strike, and `dreadmaw-combat.js::resolveAttack` for the agricultural specialist's moving rush/closure. Standard cone/sector/circle/dual-line/charge/volley/canister/pattern-charge/ring warning geometry is checked in world coordinates; actual target-locked Cindermaw actions require the Ogre to be the threatened victim, not a bystander on someone else's mark.
