**Death-mode truth:** Normal and Nightmare hero deaths **respawn** at refuge or selected Barracks with applicable penalties; Arena returns to its safe hub. They **do not** enter `challenge.gameOver`. Succession deaths remove the fallen class from the available roster; if one class remains, code may automatically select it, otherwise it prompts selection; only exhaustion ends that run. Preserve all these game rules. Do not force an artificial Game Over in Normal/Nightmare to justify the cue. No new rule that `defeat` must play on routine Normal/Nightmare respawn or Arena failure has been approved; if a short death sting there is desirable, treat it as a separate artistic/gameplay decision, not a hidden assumption.

**Phase 7 focused tests:** Nonterminal Succession death with multiple replacements, automatic final remaining replacement, terminal exhaustion, no accidental game-over in Normal/Nightmare/Arena, playback persistence over successor UI transitions, clear fade on choosing successor or exiting, priority compared to danger/SFX, and invalid/repeated events.
