# Guía del juego en español

**Esta guía cambió de nombre.** Si buscas cómo jugar en español, qué es el proyecto, sus controles, guardados y menús, abre la **[Guía completa del juego en español](GUIA_EN_ESPANOL.md)**.

Este archivo se conserva para que los enlaces antiguos a `CONTROLES.md` sigan funcionando. Los controles y el contexto actual se mantienen en la guía nueva.

## Controles de esta edición

Usa WASD para moverte y recorrer menús, F para confirmar y Esc para volver. En el teléfono, usa la palanca izquierda y el botón Confirmar. En el campo, el clic izquierdo pide curación a un compañero. El movimiento directo se controla con WASD o la palanca.

Pulsa 1–4 para la forma normal o mantén para cargar. Las habilidades aprendidas 5–8 se activan con 1–4, respectivamente, en la misma forma y con su propio rango. Los ataques básicos automáticos requieren movimiento. Consulta Ajustes → Controles para ver las teclas fijas.
