# Azeroth Chronicles — expanded prototype v0.8.50

One hero and companion adventure across five regions, ten settlements and five dungeons. Rescue ten captive specialists to purchase skills, skill ranks and equipment improvements. Ten boss families use readable but adaptive warned mechanics. Every boss can summon pressure units, while TRUE forms use six-unit elite warbands. Secret ringleaders and TRUE forms lead to the Dark Lord, the awakened dungeon finale, peace for every creature and an unlocked Nightmare campaign.

## Play

Play the live game at https://joedoragon-glitch.github.io/azeroth-chronicles-prototype/. Existing installs can use **Menu → Game and settings → Check for game update** to save the run and install the latest version. The portable copy below runs offline. On a phone, open **Menu → Game and settings → Install on phone**. Android/Chrome can launch the native install prompt; on iPhone/iPad the game gives the Safari **Share → Add to Home Screen** steps. Once installed, it launches from the home screen in app mode without normal browser chrome and can use the cached game offline after the first connected load.

For an offline portable copy, download `release/Azeroth_Chronicles_Playtest.html` and open it in Chrome or another current browser. The whole game, music and sound are embedded; no installation, server or internet connection is needed. Press a key or tap to start sound. Download the HTML instead of viewing its source in GitHub. The earlier v0.5 adventure remains available at `legacy.html`.

Choose Standard or the optional **Succession challenge**, then Paladin, Mage or Ranger. Succession retires fallen classes for that run. The first death offers the other two classes; the second automatically selects the last unused class; the third ends the run. A successor starts at level 1 in Millhaven, with zero XP, no talents and just their first skill. Gold, world progress, equipment, supplies and companions are inherited. Rescued teachers remain available. Training has no hero-level requirement: rescue access, gold and the specialist's own curriculum/rank ceiling are the gates. Normal and Nightmare have separate saves. Nightmare can also be started with the Succession challenge; the same challenge-condition choice appears before class selection in either mode.

## Controls

| Action | Keyboard / touch |
| --- | --- |
| Move | WASD / left joystick |
| Interact | E or F / Interact |
| Skills 1–5 | 1–5 / left skill buttons |
| Skills 6–8 | Space, left Shift, B / left skill buttons |
| Health / mana potion | Auto at 35%; H / M; on PC left mouse = HP and right mouse = MP; touch potion buttons remain available |
| Squad doctrine | Tab / contextual Squad button during combat after Expedition Rank 3 |
| Recall / regroup squad | Backtick / Recall squad button |
| Map / journal / inventory | Z / J / I / Menu |
| Pause / menu | P / Escape / Menu |
| Sprint | Q reserved; sprint deliberately unavailable |

Menus pause play. On PC, W/A moves to the previous menu choice, S/D moves to the next, and F/Enter/Space confirms. On touch devices, the joystick moves menu selection and Confirm activates it. The Adventure menu keeps global functions only: Map, Quest journal, Inventory, Character, the Awakening finale when relevant, contextual field-barracks construction, and Game and settings. Troop recruitment, recovery, expedition labor and routine construction live at town Captains and completed barracks instead of being duplicated inside Character. Its selectable Back entry is the single return-to-play control. Controls, sound, backups, reports and new-run management are grouped in submenus. Use the map to walk to marked captives, services and transport. Regions connect through recognizable NPC transport, rather than walking across their boundaries. Companions, finite gathering, construction and training share this same adventure and save. PC gameplay is keyboard-first: WASD always controls the hero; E/F interact; Tab switches the current squad doctrine only during an engagement; Backtick recalls and regroups the party. Mouse clicks never move the hero or issue squad commands. The deliberate PC exception is potion use: left mouse consumes an HP potion and right mouse consumes an MP potion when gameplay is active. Companions follow the hero automatically and combat roles are doctrine-driven. Paladin defaults to TARGET in field fights and BOSS in boss fights; Mage and Ranger default to THREATS and ADDS. A manual doctrine switch lasts only for the current engagement and resets automatically afterward. Soldiers and Archers can temporarily leave combat duty for expedition labor. Recall cancels labor assignments and pulls every living companion back to the hero before normal doctrine behavior resumes.
The old transient bottom message strip is replaced by a selective top-center critical notice banner. Routine combat, loot and proximity chatter stay out of it; major progression events such as level-ups, specialist rescues, TRUE boss emergence/spawn and Awakening use a distinctive amber notice for roughly five to six seconds. On touch layouts, Interact remains the protected bottom-right primary control and Recall sits above it. The contextual Squad doctrine button appears only while combat is active, using the reclaimed old squad-control space. The old Order button no longer exists during gameplay; it appears only as Confirm while a menu is open. Touch devices use the thumb-friendly controls even when the browser reports a desktop-like viewport: portrait/tall touch layouts use a large two-column power grid above the left joystick, while landscape touch layouts use four wide columns. The joystick moves menu selection; F/Confirm activates it. Touching menu entries does not activate them. The Back entry is selectable with the joystick.

## Progression and ending

Start with hero skill 1 and **Expedition Skill Rank 1**. Expedition training is free but must still be trained through a rescued instructor, either directly or through that instructor's barracks access. The six Expedition ranks are: Rank 1 baseline squad/Recall/basic 20g barracks and recovery; Rank 2 recruitment, resource labor and active-group cap 3; Rank 3 manual doctrine switching; Rank 4 full barracks and active-group cap 4; Rank 5 cap 5; Rank 6 cap 6. Mira, Sela, Orin, Lyss and Tovan train Expedition through ranks 2, 3, 4, 5 and 6 respectively, and a later instructor can train skipped earlier ranks. Hero skills 2–8 still require their rescued teachers and payment. Specialists never impose hero-level requirements on either progression system. Enemy populations are larger with smaller individual drops. Enemy XP and gold are 100%/75%/40%/10% at hero level gaps of 0/1/2/3, and 0% at a gap of 4 or more; ordinary monster XP is halved before that penalty. In Normal mode, daytime lasts six minutes and night lasts four minutes for a ten-minute cycle. Night increases health and damage after distinct first boss victories, with unchanged gold and XP.

All thirty quests are active from the start of a run. Quest boards are informational local-objective lists rather than accept/turn-in hubs, and gold/XP rewards are delivered automatically as soon as an objective completes. Existing saves activate unfinished quests and automatically deliver any already-earned unpaid rewards on load.

Two hero-participating kills of one ordinary species summon one or, with a 50% chance, two ringleaders. Companion-only kills neither advance nor reset that ordinary-monster streak. Named field bosses use independent persistent defeat counters: Thornfang, Mirejaw, Ridge Tyrant and Ashen Warlord require two hero-participating normal defeats, regardless of ordinary enemies defeated between those boss fights. Their first normal defeat uses the regular 120-second respawn; the second cancels that respawn and queues the TRUE form 5 seconds later at a different valid location in the same region. The Dark Lord is the exception: his first normal defeat immediately queues Dark Lord TRUE after the same 5-second remote-spawn transition, with no second normal Dark Lord fight. Existing saves reconstruct these entitlements from saved boss-defeat history. Active TRUE field bosses are named in the HUD and listed as hunt targets on the map. A normal dungeon boss receives one saved 1-in-3 early TRUE roll and stays dead. Reenter a cleared dungeon to challenge an available TRUE form after preparing.

Health and mana potions use themselves at or below 35% of the relevant maximum when available. MP progression is now constrained: maximum MP rises by 5 per level instead of 15, passive regeneration is 1 MP/s in combat and 2.5 MP/s outside combat before the restrained mana-talent bonus, higher skill ranks modestly increase MP cost, and Mage Recovery restores a bounded 22 + 3 per additional rank. Wraith magic and selected Crypt, Archive, Abyss, Citadel and Dark Lord attacks drain a percentage of maximum MP; ordinary physical attacks and traps do not. Existing saves normalize oversized MP pools to the new class/level curve while preserving the current MP percentage. Health takes priority if both are low, and both share the existing ten-second cooldown. Their recovery is delivered over five seconds of active play, survives reload, and stops if the resource reaches its maximum. H, M and the left-side buttons allow earlier use; the inventory menu still works. Automatic consumption saves immediately.

The first TRUE Dark Lord defeat permanently removes his family and starts Awakening, fixing the returning endgame tier at the hero’s victory level +2. A one-time **The Dungeons Awaken** screen explains the new goal and shows all five dungeon guardians as TRUE defeated, TRUE awakened, or normal boss still alive. The HUD, Adventure menu and regional map keep that finale guidance available afterward. All five TRUE dungeon guardians must fall to end the war. The remaining creatures become harmless, neutral and invulnerable; fewer inhabit the countryside, and native species inhabit the reclaimed dungeons. Each place gains a hopeful arrangement of its original melody. After the peaceful ending unlocks Nightmare, the peaceful Adventure menu visibly exposes **★ New Game — Nightmare Mode** instead of hiding it inside save/settings management.

Nightmare starts fresh and stays at night during the hostile campaign. Distinct first normal and TRUE boss defeats count independently without a formula cap; repeats do not count. Completing its finale restores the ordinary day/night cycle in a peaceful world, starting at sunset.

## Saves, sound and feedback

Autosaves occur every five active seconds and after important events. Export a backup before moving the HTML or switching devices, since browser storage for local files varies. Import validates before replacing a run. Current-run reloads preserve fallen classes and game over, but deliberately importing an old backup can rewind an offline run. No server anti-cheat is provided. The old v2 export remains untouched and is backed up on migration.

The sound menu offers independent master, music, ambience and effects volumes. Fourteen original melodic themes and ten peaceful arrangements are synthesized locally. Backgrounding and explicit pause suspend sound and combat. No external tracks or recording licenses are needed.

Choose **Menu → Game and settings → Save and game management → Export playtest report** to collect deaths, kills, boss durations, earnings and supply use. Record class, mode, challenge, session length, stuck routes, unaffordable training, unclear boss warnings, companion behavior and sound comfort. Reports stay local; no telemetry is sent automatically. Difficulty, economy, presentation and music are provisional.

Dungeon interiors now have themed decorations, 10–26 initial guardians and doubled engineered spike/jet/seal layouts placed along defensible routes while preserving safe approaches to the boss. The five main dungeons give no gold or EXP for any guardian-class enemy, including initial guards, reinforcements, awakened guards and guardian ringleaders. Base dungeon guardians are now deliberately stronger than equivalent regional field melee mobs—roughly 25–35% more HP and 12–20% more damage depending on region—before ringleader or Awakening multipliers. Existing saves upgrade old guardian stats once while preserving current health percentage.

### Monster behavior pass
Ordinary, Ringleader and guardian enemies now use more practical combat roles without changing their HP or damage. Pure ranged enemies backpedal when crowded instead of standing still at point-blank range. Mireling and Reed-beast spit applies a short slow. Ringleader hybrids commit to melee sooner, while melee Ringleaders rearm their existing pursuit burst after landing a hit so they are harder to kite indefinitely. Dungeon melee guardians screen the hero when a ranged guardian in the same pair is threatened, making guardian pairs act like a formation instead of two unrelated enemies.

This pass deliberately stops short of adding bespoke Ringleader skills. A later tuning layer can give ordinary and guardian Ringleaders one warned ranged technique inspired by the boss of their zone without turning them into miniature bosses.

### Boss mechanics pass
Bosses no longer follow a fixed 1 → 2 → 3 → 4 script. Attack choice is weighted by player distance, current phase and living summons, and the same move cannot immediately repeat. Selected control mechanics pressure the hero directly instead of always being absorbed by companions. Below half health, each boss can chain specific existing mechanics while keeping their normal warnings readable.

Normal summon actions maintain up to **3 ordinary boss-owned adds** with a short summon cooldown. Every TRUE boss normally maintains **6 boss-owned summons: 4 enhanced minions + 2 Ringleader captains**. **Ashen Warlord is the deliberate commander exception:** 4 normal guards, and an 8-unit TRUE warband made of 6 enhanced orcs + 2 Ringleader captains. Summon actions and half-health reinforcement refill missing roles rather than stacking beyond each boss's cap. Stone Colossus and Ash Sentinel now have authored summon mechanics as well. Ranged boss summons and TRUE captains prioritize the hero when practical, making the warband mechanically relevant rather than only extra HP and damage.

### Light combat VFX pass
Ranged attacks now read as their actual material instead of generic glowing orbs: Ranger and companion archer shots render as arrows; orc throwers use spinning axes; stones, spit, cinders, spectral shots and magic bolts have distinct silhouettes and restrained trails. Melee swings, impacts, healing/mana recovery and short-lived immunity/haste/potion states also receive small readable effects without changing combat mechanics. This prevents the 18-second reinforcement loop from becoming a farming exploit; boss, rescue and first-clear rewards remain the dungeon incentives. Guardians used by separate outdoor mini-dungeons and quest interiors keep their own reduced-reward rules.

After the TRUE Dark Lord falls, the hero’s level at that victory is saved. Unbeaten returning TRUE dungeon bosses are fixed at that level +2, and their awakened guardian waves use exactly that same level. Awakened guardians also receive a dedicated 35% health and 25% damage increase before regional guardian scaling, and any later reinforcements inherit those awakened stats. Their health and damage also rise with the captured level above 18, retaining the original endgame values as minimums. Later level-ups, reloads and Succession do not change this tier.

Ringleaders have twice the regular variant’s base health, 25% more damage and 10% faster movement. This applies to guardian ringleaders too. Existing elites retain their current health fraction when upgraded.

Equipment now auto-selects the strongest owned option: higher armor tiers are immediately active, and newly acquired weapon tiers automatically replace the current weapon only when they beat the best owned legacy weapon. Specialists have explicit learning and training catalogues: Mira teaches skill 2 and trains only 1–2; Sela teaches 3/4/6 and trains 1/2/3/4/6; Orin teaches 5 and trains 1–6; Lyss teaches 7 and trains 1–7; Tovan teaches 8 and trains 1–8. Rank caps remain 2/3/4/6/8. Specialist services have no hero-level gates: a player who reaches and rescues a specialist early may immediately buy anything that specialist offers, provided they have the gold and satisfy the specialist's curriculum/tier prerequisites. Future skill names stay hidden until their region is reached, their teacher is rescued, or the skill is already known. Existing learned skills remain available.

Instructor curriculum and rank ceilings, smith equipment tiers, reforge ownership and gold costs remain the progression limits. This deliberately rewards skilled sequence-breaking and speedrunning without changing encounter access, rescue requirements or specialist order.

Field-barracks update v0.8.42 turns player-built barracks into persistent regional command bases. A living Worker / Builder can establish one outdoors for 120g. Completed barracks provide an Operations board, consolidated rescued-specialist access, discounted recruitment at 30g Worker / Builder, 60g Soldier and 85g Archer, fallen-companion recovery, worker/resource orders and Inventory access. Town Captains retain the same safe troop-logistics categories at normal town recruitment prices of 35g / 70g / 100g. Older specialist entries disappear when a later rescued specialist fully supersedes them, while instructors remain listed if they still own an unlearned unique skill. Barracks are map-visible and retain their region. Their construction art now uses distinct Greenwood timber, Marches raised wetland construction, Highlands stone/ore details, Frontier scorched fortification and Dark Crown dark-stone/arcane materials.

Companion-recovery update v0.8.43 completes troop sustain. Resting at a refuge now fully restores every living companion alongside the hero while leaving fallen companions fallen. Completed barracks offer **Treat wounded companions · 30g**, restoring all living wounded companions to full health when no nearby enemy is actively engaged. Fallen units remain a separate casualty state and require **Recover fallen companion · 40g** through a town Captain or barracks. Hero potions and hero recovery skills still affect only the hero, and the Citadel preparation fountain retains its special one-time 60% living-companion heal.

Unified squad-control update v0.8.44 removes the separate squad-cursor game mode, field unit selection, individual move/attack orders and Hold Fire. WASD/joystick always controls the hero. Combat troops interpret the hero and one binary doctrine automatically: **TARGET ↔ THREATS** in ordinary fights and **BOSS ↔ ADDS** when a boss is engaged. Paladin defaults to TARGET/BOSS; Mage and Ranger default to THREATS/ADDS. Tab or the contextual Squad button switches doctrine for the current engagement only, then the class default restores automatically after disengagement. Recall remains the emergency regroup command. Captain and barracks menus no longer contain battlefield squad-command controls.

Role-formation update v0.8.45 makes party movement class-aware and role-aware. Formation orientation follows the hero’s recent travel direction. Mage and Ranger keep Archers in a tight pack near the hero and Soldiers farther out as a protective screen. Paladin keeps Soldiers in the close melee pack and Archers farther behind the hero/Soldiers. Role slots are assigned by unit type rather than raw recruitment order.

Expedition-party update v0.8.46 completes the approved autonomous-party pass. New games start with one Soldier and one Archer; Worker is no longer a recruitable unit. Existing saved Workers convert safely into Soldiers while preserving carried resources and health proportion, and legacy Worker training queues resolve as Soldiers. Any idle Soldier or Archer can provide expedition labor: selecting a resource assigns all currently idle troops to gather/deposit/return automatically, while barracks construction assigns exactly one idle troop and leaves the hero free to guard the site. Recall cancels labor without erasing construction progress. Soldiers now screen enemies pressing the hero or back line under THREATS/ADDS, while TARGET/BOSS still obey the doctrine target directly. Archers fight from their class-aware formation side, step forward only far enough to gain firing range, and fall back toward formation when rushed. Nearby aggro—not hero participation—is the encounter boundary, so the squad defends the hero immediately when attacked.

Expedition-skill update v0.8.47 makes the squad/field system part of the specialist rescue loop instead of front-loading it. Rank 1 is learned by default and includes the starting Soldier + Archer, Recall, and cheap 20g Basic Barracks with recovery and rescued-specialist access. Rank 2 (Mira) unlocks recruitment, resource labor and a three-companion active group. Rank 3 (Sela) unlocks manual doctrine switching. Rank 4 (Orin) unlocks four active companions and Full Barracks: existing Basic Barracks upgrade for exactly 100g with companion labor, while all newly built barracks cost 120g and start full. Full Barracks are resource deposit points and expose the complete operations package. Rank 5 (Lyss) and Rank 6 (Tovan) raise the active group to five and six. Expedition ranks cost 0g but must be trained from a rescued instructor; advanced instructors can cover skipped lower ranks. Town hiring stops after three total employed companions, including resting and fallen units, and explicitly directs the player to build a barracks. Barracks recruitment can continue into a large reserve; only the Expedition rank limits how many companions travel with the hero. Barracks group management moves companions freely between the active group and resting reserve.

Companion-scaling fix v0.8.48 updates every existing Soldier and Archer whenever the hero gains a level. Companion max HP is recalculated from the current hero level; living companions gain only the newly added max-HP amount so existing wounds are preserved, while fallen companions remain at 0 HP. Companion attack damage and armor already used the hero's current level dynamically.

Ordinary-ranged balance v0.8.49 gives ordinary outdoor ranged variants their own regional HP/damage scaling instead of leaving them on the old unscaled base curve. The ranged curve remains deliberately below melee: HP multipliers are 1.05/1.10/1.20/1.35/1.55 and damage multipliers are 1.00/1.05/1.10/1.20/1.35 from Vale through Crown. This leaves ranged enemies weaker body-for-body because they attack from distance and retreat, while preventing late-game ranged mobs from collapsing to roughly half the strength of equivalent melee enemies. Existing saves upgrade affected ordinary ranged enemies once while preserving their current health percentage.

Companion-inheritance update v0.8.50 adds two paid four-rank support skills with live 25/50/75/100% inheritance. **Shared Training** is taught by Orin and makes companions inherit the hero's talent-derived HP and damage. **Shared Strength** is taught through the equipment-specialist ladder—Borin Rank 1, Dara Rank 2, Eren Rank 3 and Vera Rank 4—and makes companions inherit the hero's other bonus HP and damage above the natural class/level baseline. Later specialists can cover skipped lower ranks one step at a time. Both skills immediately catch existing companions up when learned and continue updating automatically as the hero's eligible stats change. Each skill has exactly four purchases and no player-facing Rank 0 or fifth upgrade. Shared Training is cheaper because the talent bonus pool is smaller: 150g / 250g / 400g / 600g for Ranks 1–4 (1,400g total). Shared Strength remains 250g / 400g / 600g / 850g (2,100g total) because equipment/reforge and other non-talent bonus growth provide the larger inheritance pool.
