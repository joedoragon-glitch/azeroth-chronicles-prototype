# Phase 3 — compact CC0 performance samples (studio candidate)

These original, unmodified compact MP3 source clips are redistributed from **tiny-orchestra 0.2.0** by MarianBecher, pinned to [commit 60f3d59d4a797e0b0815c8dbd23aaa3cd723eb6f](https://github.com/MarianBecher/tiny-orchestra/commit/60f3d59d4a797e0b0815c8dbd23aaa3cd723eb6f). Its source samples were edited from **VSCO-2 Community Edition** (Versilian Studios / Samuel Gossner and contributors). Both projects state **CC0 1.0** public-domain dedication for these samples; see the [upstream credit](https://github.com/MarianBecher/tiny-orchestra/blob/60f3d59d4a797e0b0815c8dbd23aaa3cd723eb6f/CREDITS.md) and [upstream license](https://github.com/MarianBecher/tiny-orchestra/blob/60f3d59d4a797e0b0815c8dbd23aaa3cd723eb6f/LICENSE).

- This bank is **only for isolated Phase 3 production QA**, not the registered PWA catalog, user downloads, gameplay runtime, or the deferred Dark Crown cues. **The current Phase 3 renderer does not yet use the bank.** See [curated artistic-source workflow](../../../docs/ARTISTIC_ASSET_WORKFLOW.md) for how this material must be evaluated before use.
- Each file is copied byte-for-byte and pinned by its source Git blob hash in [phase3-sample-bank.json](../phase3-sample-bank.json).
- These reduced-size files use mono, previously lossy MP3. A better recording source, carefully authored performances, musical mix and actual critical listening may still be needed for final quality. **The user has not auditioned these and Phase 4 remains on hold.**
- Do not conflate sampler authenticity with demonstrated orchestral quality. Report file and note-register tests separately from real listening, which remains UNVERIFIED.

## Second source: recorded CC0 piano

Eight Ogg Vorbis clips, six pitches and two alternative gentle velocities, pinned from [Meta Piano / Meta-open-sound](https://github.com/facebookincubator/Meta-open-sound/tree/251c0be57d5d1b3242b91f53e0cde62ab1cb42d9/systems/instruments/meta-piano). The specific [CC0 1.0 license](https://github.com/facebookincubator/Meta-open-sound/blob/251c0be57d5d1b3242b91f53e0cde62ab1cb42d9/systems/instruments/meta-piano/LICENSE) applies. Sources originated as 48-kHz 24-bit stereo piano recordings, distributed as mono Ogg; this is a deliberately sparse subset, not an approved piano sound. Preserve hashes and listening caveats.

## Third instrument — recorded nylon guitar, same CC0 source as piano

Six warm fingerstyle nylon-string guitar clips from [Meta Open Sound's nylon guitar collection](https://github.com/facebookincubator/Meta-open-sound/tree/251c0be57d5d1b3242b91f53e0cde62ab1cb42d9/systems/instruments/meta-nylon-guitar), same pinned upstream revision. Its [instrument-specific CC0 1.0 license](https://github.com/facebookincubator/Meta-open-sound/blob/251c0be57d5d1b3242b91f53e0cde62ab1cb42d9/systems/instruments/meta-nylon-guitar/LICENSE) applies. They cover MIDI 40–64 sparsely; re-pitching and temporal articulation require explicit technical and perceived-quality review. The source also provides other plucking dynamics, not yet selected or approved.
