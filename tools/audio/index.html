What is a scene preview?

A preview uses the actual soundtrack catalog and mixing rules. Exploring usually plays the main melody; combat adds a synchronized action layer. Boss music has a normal and a stronger TRUE treatment. These are audio previews, not playable battles or proof of device-quality mastering.

2 · Complete library

Browse individual recordings

Every registered music track, environmental recording and sound effect can be selected below. Unlike a scene preview, a single recording lets you hear one file by itself.

Choose a recording to see its name, purpose and source.

Choose a main exploration theme or boss theme with a matching second layer to compare them together.

Why would I play two layers?

In combat, the game can keep the main melody playing while adding rhythmic action music. Bosses likewise use a synchronized TRUE layer. This lets you audition that combination and adjust how prominent the second part sounds.

3 · For sound creation

Understand or rework a sound

Every production recording has a reusable creative brief. Select a track above to read its design instructions, then copy the brief if you want to discuss a replacement or give a composer a starting point. The brief describes the sound; it is not the original prompt used to create it.
