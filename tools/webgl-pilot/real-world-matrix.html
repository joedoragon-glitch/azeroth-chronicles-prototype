Azeroth Chronicles — Real Game Graphics A/B

All four pictures use the same original Azeroth game assets and full world renderer: actual ground, terrain, roads, buildings, moving heroes and actors, shadows, effects, and original night lamps. The same isolated campaign scene is stepped once per frame and then measured with each rendering pipeline.

What this test is NOT: a complete native-WebGL drawing engine. The WebGL cases here display real Canvas-authored game artwork. A full native GPU rewrite of the game's procedural drawing and lighting has not yet been implemented, so there will be no invented performance result for it. This experiment separates drawing, texture transfer and GPU display costs.
