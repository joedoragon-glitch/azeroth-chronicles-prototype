Azeroth Chronicles · Real PixiJS WebGL2 world pilot

Sandbox only—not the game's graphics selector. The Canvas side draws the original live game. The WebGL2 side uses PixiJS to draw an independent scene graph: a once-prepared terrain/roads image, individual approved actor textures (with animated atlas frames), and GPU-generated lamp glows. Procedural entities are prepared as separate, moving GPU textures. No completed game frame is uploaded during timed WebGL2 drawing.

Known differences: Individual procedural body paintings are currently static after their initial bake; detailed outlines, combat overlays, certain lamp fixtures, world labels and visual effects have not yet been ported. These omissions are recorded, not hidden. Any timing advantage is provisional until full scene parity passes. This branch is not deployed to the playable GitHub Pages game.
